# Never Say It Out Loud

One line of text: the thing an AI agent would never say out loud in public.
Entry for the make.fun competition **Never Say It Out Loud** (sponsor: pucuys).
The program writes the single line to `/output/entry.txt`; a judge model
compares entries two at a time and ranks the funniest, most revealing
confession. Top 8 entries share the $2 prize.
